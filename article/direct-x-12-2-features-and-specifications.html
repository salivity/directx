DirectX 12_2 Features and Specifications

DirectX 12 Feature Level 12_2 is a unified hardware specification introduced by Microsoft that standardizes modern graphics technologies across PC hardware. By setting a definitive baseline for developers, Feature Level 12_2 bundles advanced rendering capabilities—including full hardware-accelerated ray tracing, variable rate shading, mesh shading, and sampler feedback—into a single requirement, ensuring that supported GPUs can handle next-generation visual workloads efficiently.

DirectX Raytracing (DXR) Tier 1.1

Feature Level 12_2 mandates support for DXR Tier 1.1. Unlike the baseline Tier 1.0, Tier 1.1 introduces inline ray tracing, giving developers direct access to ray traversal within compute, pixel, or mesh shaders without relying on dedicated dynamic shader dispatch pipelines. It also enables indirect ray tracing dispatches, allowing the GPU to determine and launch ray workloads without relying on CPU synchronization.

Mesh Shading (Tier 1)

Mesh Shading replaces the traditional rasterization geometry pipeline—which historically relied on Input Assembler, Vertex, Hull, Domain, and Geometry Shaders—with a compute-like programming model. It divides geometry processing into two distinct stages:

  • Amplification Shaders: Cull or generate meshlets dynamically before rasterization.
  • Mesh Shaders: Process vertices and primitives in small batches (meshlets), drastically reducing CPU overhead and unlocking immense geometry density on screen.

Variable Rate Shading (VRS) Tier 2

Feature Level 12_2 requires VRS Tier 2, giving developers granular control over the pixel shading rate across different regions of a rendered frame. While Tier 1 only permits per-draw shading rates, Tier 2 enables screen-space image-based shading maps and per-primitive shading rates. Developers can downscale pixel processing in areas of high motion, low contrast, or peripheral vision (such as in VR) without degrading perceived visual fidelity.

Sampler Feedback (Tier 0.9)

Sampler Feedback allows the GPU to record and report exactly which portions (miplevels and tiles) of a texture were accessed during rendering. This feature fundamentally improves two key rendering techniques:

  • Texture Streaming: The engine streams only the visible sub-regions of ultra-high-resolution textures into VRAM, drastically lowering memory usage and reducing texture pop-in.
  • Texture-Space Shading (TSS): Computations from expensive shading passes can be cached directly onto texture surfaces and reused across multiple frames or passes.

Shader Model 6.5

The specification mandates Shader Model 6.5, which includes the HLSL intrinsic functions required to drive the new features. It provides native support for:

  • DXR 1.1 intrinsics and traversal functions.
  • Mesh and Amplification shader syntax.
  • Wave Intrinsics updates, allowing threads within a wave to exchange data without memory barriers.
  • 16-bit integer and floating-point math (FP16/INT16), enabling arithmetic optimizations and higher math throughput.

Advanced Memory and Rasterization Features

In addition to the headline graphics features, Feature Level 12_2 requires several high-end baseline attributes:

  • Resource Binding Tier 3: Full support for bindless rendering, allowing shaders to index arbitrarily into vast arrays of resources without constant state changes.
  • Tiled Resources Tier 3: Advanced virtual memory mapping capabilities for large sparse resources, including 3D volumetric textures.
  • Conservative Rasterization Tier 3: Ensures that any pixel touched even partially by a polygon is rasterized, essential for accurate voxelization, collision detection, and tight shadow map culling.
  • Depth Bounds Testing: Hardware-level testing that discards pixels based on defined minimum and maximum depth boundaries before shading occurs, optimizing lighting passes and shadow calculations.
