DirectX Feature Level 12_2: Features and Supported GPUs

DirectX Feature Level 12_2 is an advanced hardware specification tier introduced by Microsoft to set a uniform baseline for modern graphics rendering technologies across PC and console gaming. This article details the core graphics functions mandated by Feature Level 12_2—such as hardware-accelerated ray tracing, variable rate shading, mesh shaders, and sampler feedback—and outlines the specific graphics architectures from NVIDIA, AMD, Intel, and Qualcomm that provide full hardware support.

Core Functions of DirectX Feature Level 12_2

DirectX Feature Level 12_2 consolidates the cutting-edge features originally branded under the DirectX 12 Ultimate umbrella, requiring graphics hardware to meet strict implementation standards across several key graphics pipelines:

  • DirectX Raytracing (DXR) Tier 1.1: Mandates support for hardware-accelerated ray tracing with dynamic ray generation and inline raytracing. This enables games to calculate reflections, shadows, ambient occlusion, and global illumination efficiently without offloading the intensive work entirely to general-purpose compute pipelines.
  • Variable Rate Shading (VRS) Tier 2: Allows the GPU to dynamically allocate shading power across different regions of a frame. By reducing shading detail in areas of high motion or low visual contrast while preserving full resolution in focused areas, the GPU achieves significant performance gains without noticeable degradation in visual fidelity.
  • Mesh Shaders Tier 1: Replaces the legacy input assembler and vertex/geometry/hull shader pipelines with modern Amplification and Mesh Shading stages. This grants developers fine-grained compute-like control over geometry processing, drastically increasing the number of complex objects and polygons that can be rendered simultaneously.
  • Sampler Feedback Tier 0.9 and Tier 1: Enables the GPU to record and report exactly which portions of a texture mipmap are required for rendering. This optimizes texture streaming systems, drastically reduces VRAM consumption, and accelerates advanced techniques like Texture-Space Shading.
  • Shader Model 6.5: Guarantees support for enhanced HLSL constructs, ray tracing intrinsics, integer 8-bit dot products (useful for light machine learning acceleration), and 16-bit floating-point operations.

Architectures that Fully Support Feature Level 12_2

To achieve full Feature Level 12_2 compliance, a GPU architecture must implement all of the above capabilities at the hardware level. The following hardware architectures fully support this specification:

NVIDIA

  • Turing (RTX Only): GeForce RTX 20-series and Quadro RTX cards (TU102, TU104, and TU106 silicon). Note that non-RTX Turing GPUs (GTX 16-series) lack the necessary hardware-accelerated ray tracing units and do not qualify.
  • Ampere: GeForce RTX 30-series, RTX A-series, and mobile RTX GPUs.
  • Ada Lovelace: GeForce RTX 40-series and workstation Ada GPUs.
  • Blackwell: Next-generation GeForce and enterprise architectures.

AMD

  • RDNA 2: Radeon RX 6000-series desktop and laptop GPUs, as well as integrated custom processors in modern gaming consoles (PlayStation 5 and Xbox Series X/S).
  • RDNA 3 and RDNA 3.5: Radeon RX 7000-series desktop GPUs, mobile Radeon units, and integrated graphics found in newer Ryzen processors (such as the Radeon 700M and 800M series).

Intel

  • Xe-HPG: Intel Arc Alchemist discrete desktop and mobile GPUs (A-Series: A770, A750, A580, A380, etc.).
  • Xe2 (Xe2-LPG & Xe2-HPG): Lunar Lake integrated processors and discrete Intel Arc Battlemage GPUs.

Qualcomm

  • Adreno X1 Series: Found within Snapdragon X Elite and Snapdragon X Plus platforms designed for Windows on ARM, providing native hardware support for modern DirectX 12 Feature Level 12_2 workloads.
